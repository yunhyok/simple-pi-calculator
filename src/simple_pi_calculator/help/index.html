Simple PI Calculator

Simple PI Calculator computes and plots the impedance magnitude |Z(f)| of the power-distribution network (PDN) as seen from an IC PAD, separately for every power net (PWR) of a PCB or multilayer organic (MLO) substrate. It is a fast, first-order, frequency-domain "what-if" tool for early decoupling-capacitor (decap) planning: How many capacitors? Which values? How far from the IC? How many vias? It is not a full-wave field solver.

What is modelled

For each PWR net the tool builds the chain below: every decap (a SPICE .mod subcircuit or a Touchstone .s2p measurement) is connected through its vias to a PWR/GND plane pair. The plane pair behaves as a cavity resonator with one port per via set. The IC PAD is connected to the same plane pair through its own vias. The result is the impedance looking into the PAD.

Figure 1 – The modelled PDN chain for one PWR net.

Main features:

  • Stack-up, PWR list and decap list imported from Excel files with tolerant ("fuzzy") header recognition.
  • Physics-based cavity model of the plane pair including dielectric and conductor losses and plane resonances.
  • Via-pair loop model using the real via length to the nearer plane, drill, anti-pad and via pitch.
  • Decap models from vendor SPICE subcircuits (R, L, C, K elements, parameters, nesting) or S-parameter files.
  • Dummy Cap option for capacitors that share one via set.
  • Log-log plot per PWR with markers at 1 MHz, 10 MHz and 100 MHz, unit switching (Ω / mΩ / µΩ), zoom and export.
  • Continuous auto-save of everything you do, plus named project files for sharing.

Typical workflow in one minute

  1. File ▸ Open Example Project to see a complete setup, or start with File ▸ New.
  2. Import the stack-up (format).
  3. Check the via settings (details).
  4. Import or type the PWR nets (format) and the decap rows (format).
  5. Press F5 (Compute ▸ Run) and read the plot (how to read).

The complete step-by-step tour is in Getting Started.

Conventions used in this Help

  • Lengths in the user interface and Excel files are in mm unless a unit is given; inductance in nH; |Z| in mΩ by default.
  • Layer 1 is the top of the stack-up; decaps and the PAD are on the Top side.
  • Message codes start with E_ (error, blocks the computation of the affected PWR), W_ (warning, result is produced but check it) or I_ (information).
  • Tags such as [Okoshi85] point to the References.
Accuracy in one sentence. The tool is intended for relative comparisons and first estimates up to about 1 GHz: the plane is a synthetic rectangle derived from your decap distances, so plane resonance frequencies and the plane-only curve are indicative; see Limitations.
