Input: PWR list

The PWR list defines the power nets to analyse. Each row names a PWR plane layer, the GND plane layer used as its reference and the width of the plane. Rows can be imported from Excel (PWR Nets tab ▸ Import… or File ▸ Import ▸ PWR List…) or entered directly with Add. Duplicate copies the selected row, which is handy for variants.

The rules are applied in the order GND layer → PWR layer → PWR name → Width, so GND Layer Number is never mistaken for the PWR layer, whatever the column order. The general header, sheet (name containing pwr or power) and number rules are the same as for the stack-up.

Columns whose header contains height, length or pad (from older templates) are ignored with W_XL_COLUMN_IGNORED: the plane height and the PAD position are derived automatically.

Choosing the GND reference

  • Use the GND plane adjacent to the PWR plane, normally the one with the thinnest dielectric in between. A thin dielectric gives a high plane capacitance and a low spreading inductance.
  • Only one GND layer is used. If the PWR plane is sandwiched between two GND planes, pick the closer one; the second cavity is not modelled (conservative).
  • If a metal layer lies between PWR and GND, it is assumed to be removed in the plane area (W_STACK_METAL_BETWEEN). More than 3 layers in between gives W_PWR_FAR_GND.
  • The nearer of the two layers (smaller layer number) sets the via length; see Via length.

Width and derived plane height

The real plane outline is not an input. The tool builds a synthetic rectangular plane:

  • Width W (your input) – the extent of the plane across which the decaps of a row are spread. Use the width of the plane region between the IC and the capacitors (for a plane that is wider than the area where decaps can be placed, use the width of that area).
  • Height H = 1.4 × D_ref (derived) – D_ref is the largest decap distance of the net. The PAD sits at 0.2 × D_ref from one end, the farthest decap row at 1.2 × D_ref, leaving a 20 % margin at both ends.
  • If the net has no enabled decap rows, the plane is square (H = W) and only the plane-only result is computed (W_PWR_NO_DECAPS).

Figure 1 – Synthetic plane W × 1.4·D_ref with the PAD near the bottom edge and the decap rows at their distances. The x margin is 10 % of W plus half a port.

Example: VDD_CORE, W = 60 mm, decap rows at 8 mm and 15 mm → D_ref = 15 mm, H = 21 mm, PAD at (30, 3) mm, C_plane = 480 pF (d = 0.1 mm, εr = 4.3). VDD_IO, W = 30 mm, rows at 5 mm and 10 mm → H = 14 mm, PAD at (15, 2) mm, C_plane = 160 pF.

The consequences of this approximation are explained in Modelling concept and Limitations.
