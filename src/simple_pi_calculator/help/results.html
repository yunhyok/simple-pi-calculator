Results and plot

After Compute ▸ Run (F5) the right side of the window shows one plot tab per computed PWR net and a readout table. This page explains how to read and use them, how to set the sweep and how to export.

The zoom state of each plot is remembered by the auto-save and restored with the next start.

Switching the |Z| unit

View ▸ |Z| unit selects Ω, mΩ (default) or µΩ. The axis label, marker labels, hover readout and readout table change together, and the current zoom is kept (the vertical range is rescaled). The unit is saved with the project. Exported files always contain values in Ω.

Plane-only curve

Tick View ▸ Show plane-only curve (or the check box in the Sweep tab) and compute again. The dashed curve shows the plane pair alone as seen through the PAD vias. It helps to see where the plane capacitance takes over from the decaps and where plane resonances appear. Because the plane is synthetic (W × 1.4·D_ref), treat its exact level and resonance frequencies as indicative.

Interpreting the curve

  • Falling line at the left (−20 dB/decade): capacitive region, |Z| ≈ 1/(2πf·C_total). It keeps rising towards low frequency because no voltage regulator is modelled – this is expected.
  • Dips: series resonances of the decaps with their loop inductance; the depth is set by the ESR in parallel.
  • Rising line (+20 dB/decade): inductive region; compare the level between two variants to see the effect of vias, distance and count. The inductance can be read as L ≈ |Z| / (2πf).
  • Peaks: anti-resonances between capacitor groups, or plane resonances near the top of the range.
  • "(inputs changed)" in the plot title: the inputs were edited after this result was computed; press F5.

More background: What shapes the curve.

Target impedance. The tool does not draw a target line. A common first estimate is Z_target = (supply voltage × allowed ripple) / transient current, e.g. 1.0 V × 3 % / 5 A = 6 mΩ. Compare it with the marker readouts and the curve between the lowest and highest frequency of interest.

Sweep settings

FieldDefaultRules
f start100k≥ 1 kHz and below f stop.
f stop1G≤ 20 GHz; above 3 GHz you get W_SWEEP_HIGH (model accuracy).
Points40010 … 5000, logarithmically spaced. More points only make the curve smoother; marker values are always exact.
Show plane-only curveoffAlso compute the plane-only curve.

Frequency fields accept engineering notation: 100k or 100K = 1e5, 2.5M, 2.5meg, 2.5MEG or 2.5MHz = 2.5e6, 1G or 1GHz = 1e9, plain numbers such as 1e8. A lower-case m is rejected on purpose, to avoid confusing milli and mega. Invalid ranges give E_SWEEP_RANGE.

Messages dock

All issues of the last validation or computation are listed with severity icon, code, message, source (file or PWR:name) and location (sheet cell, file line or table row). Double-click a message to jump to the tab and row concerned. Hide or show the dock with View ▸ Show Messages dock. See Troubleshooting for every code.

Export

MenuOutput
File ▸ Export ▸ Results CSV…One file per PWR, named <project>_<PWR>.csv, in the chosen folder. Columns Frequency (Hz), Re Z (Ohm), Im Z (Ohm), |Z| (Ohm) and, if enabled, |Z| plane only (Ohm). A header block lists an input summary and the marker readouts.
File ▸ Export ▸ Results XLSX…One workbook with a Summary sheet (inputs and marker readouts) and one sheet per PWR with the same columns (sheet names are shortened to 31 characters; characters []:*?/\ are replaced by _).
File ▸ Export ▸ Plot PNG…Image of the visible plot (1600 px wide) with the current zoom, unit and markers.

Numbers are written with 10 significant digits in Ω, so exported data can be post-processed or overlaid with measurements in other tools. Complex values allow you to recombine results (e.g. add a VRM model externally).
