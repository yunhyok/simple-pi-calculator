Input: Via settings

The Vias tab holds the via geometry shared by all PWR nets and all decap rows. Via inductance is often the largest single contribution to the PDN impedance above a few MHz, so these few numbers matter.

The via-pair loop

Figure 1 – A via pair: current flows down the PWR via and returns up the GND via. The loop above the nearer plane dominates the inductance.

Each via set consists of PWR vias and GND vias placed next to each other. The current of a capacitor goes down its PWR via to the PWR plane and returns through the GND plane and the GND via. The model splits the via path into three segments:

  1. Above the nearer plane (length h_near): the PWR via and GND via form a two-wire loop with spacing s_v. Its inductance L_pair grows roughly with h_near × ln(s_v / r0). This is the dominant part.
  2. Through the nearer plane (thickness t_near): only the via that continues to the far plane passes the plane, inside its anti-pad. This short coaxial segment adds L_ap = (µ0/2π)·t_near·ln(r_ap/r0).
  3. Across the cavity (gap d between the planes): this part belongs to the cavity model (cavity ports) and is not counted again.

Via length: the nearer plane

All components are on the Top side, so the via length is the depth of the nearer plane of the pair (the one with the smaller layer number), measured from the Top surface to the top face of that plane:

nearer layer n = min(PWR layer, GND layer)
h_near         = z_top(n)                   (see the z_top column of the Stack-up tab)
h_R            = 2·h_near + t_near          (conductor length used for the via resistance)
Example (drill 0.2 mm, anti-pad 0.5 mm, pitch 1.0 mm)nearer layerh_nearL_loop per pairR at 1 MHz

The same plane pair can therefore behave very differently depending on its depth: planes close to the component side give short, low-inductance via loops. If the nearer plane is layer 1 itself, the via length is zero and only the anti-pad segment remains (W_VIA_ZERO_LENGTH).

Choosing the via pitch

  • Use the typical centre distance between a capacitor's PWR via and its GND via (for a 0402 with vias at the pad ends often 0.5–1.0 mm; for via-in-pad designs smaller).
  • The inductance depends on the logarithm of s_v / r0: halving the pitch from 1.0 mm to 0.5 mm with a 0.2 mm drill reduces the long-via inductance by about 30 %.
  • The pitch must be larger than the drill (E_VIA_PITCH). If the GND via would cut into the PWR via's anti-pad, i.e. s_v < (D_drill + D_antipad)/2, you get W_VIA_PITCH_SMALL.

Vias per decap pad and PAD vias

A decap has two pads. With n_pad vias on each pad, one decap via set consists of n_pad PWR vias and n_pad GND vias, i.e. n_pad PWR/GND via pairs in parallel. Every observation PAD has its own via set with its own count of via pairs (PAD vias = vias per observation pad); with several PADs per net the number of PAD via sets grows with the number of PADs. More via pairs reduce the impedance in two ways:

  • Above the planes the pairs act as parallel paths: the via impedance of a decap via set is Z_viapair / n_pad, and at each PAD Z_viapair / (PAD vias). Mutual inductance between neighbouring pairs is neglected, which is optimistic for closely packed vias.
  • Inside the cavity the vias of one set spread the current over a larger area. The set is represented by one wider square port (a via cluster), which reduces the spreading inductance between PAD and decaps.

Figure 2 – A via, or a checkerboard cluster of vias, is replaced by a square port of equal geometric mean distance. n_p = PAD vias for each PAD, vias per decap pad (n_pad) for a decap.

The cluster is assumed to be a checkerboard of alternating PWR and GND vias with nearest spacing s_v, filled row by row. Port widths for drill 0.2 mm and pitch 1.0 mm: 1 pair 0.224 mm, 2 pairs 0.841 mm, 4 pairs 1.779 mm, 9 pairs 3.451 mm. The anti-pad diameter does not change the port width. Wider decap ports also change the placement: the decap port width w sets the x margin and, for crowded rows, the sub-row pitch (placement).

Projects saved with schema 1 stored vias_per_decap (PWR + GND vias of a set, e.g. 2 or 4); they are converted automatically to vias_per_pad = vias_per_decap / 2 (2 → 1, 4 → 2), so the results do not change.

Resistance

The via resistance is the resistance of a plated tube over h_R with a smooth transition from the DC value (plating thickness) to the skin-effect value at high frequency. Example for 1 mm of a 0.2 mm via with 25 µm copper plating: 1.25 mΩ at 1 kHz, 1.34 mΩ at 1 MHz, 4.9 mΩ at 100 MHz, 13.8 mΩ at 1 GHz.
