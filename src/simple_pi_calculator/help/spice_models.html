Decap models: SPICE .mod files

The preferred decap model is a two-terminal SPICE subcircuit as published by capacitor vendors (files ending in .mod, .lib, .sp, .cir, .sub or .inc). The tool reads the linear R, L, C and K (coupling) elements, resolves parameters and nested subcircuits, and computes the impedance between the two pins with an AC circuit solver. No external simulator is needed.

A minimal model, annotated

The arrows and text after <- are explanations and not part of the file.

* Simple PI Calculator example model (synthetic, not vendor data)   <- comment line (starts with *)
* 0.1 uF 0402 X7R MLCC, series R-L-C
.SUBCKT CAP_0402_100NF 1 2        <- name, then the two pins: pin 1 = PWR side, pin 2 = GND side
R1 1 11 30m                       <- ESR 30 mΩ between node 1 and node 11 (m = milli)
L1 11 12 0.45nH                   <- ESL 0.45 nH (the trailing "H" is ignored)
C1 12 2 100nF                     <- capacitance 100 nF
.ENDS CAP_0402_100NF              <- end of the subcircuit

This model has its series resonance at f0 = 1/(2π√(LC)) = 23.7 MHz with |Z(f0)| = 30 mΩ. The Decaps tab shows it as C @100 kHz ≈ 100 nF and SRF ≈ 23.7 MHz.

Not supported (error E_SPICE_UNSUPPORTED)

  • .INCLUDE, .LIB (as a statement), .FUNC – copy the included subcircuit into the file instead.
  • Sources and non-linear or behavioural elements: V I E F G H B D Q M J T S W U O elements, including LAPLACE or frequency-table sources. DC-bias and temperature models that rely on them cannot be used.

Syntax rules

  • Lines starting with * are comments. ; anywhere, and $ after a space, start an inline comment.
  • A line starting with + continues the previous line.
  • Everything is case-insensitive, including node names. The first line is not treated as a title.
  • Parentheses and commas in node lists are treated as spaces: X1 (a b) SUB.
  • Spaces around = are allowed: C = 1n.
  • Node 0 or GND used inside a subcircuit is joined with pin 2 of the top-level subcircuit (W_SPICE_GLOBAL_GND).
  • Files are read as UTF-8, with Latin-1 as fallback.

Classic SPICE traps.

Parameters and nesting

Values can refer to parameters. When a subcircuit is instantiated, its parameter set is built from:

  1. the parameters visible to the caller (for the top level: global .PARAM lines, evaluated in file order);
  2. the defaults on the .SUBCKT … PARAMS: line;
  3. the overrides on the X line (evaluated with the caller's parameters). Overriding a parameter the subcircuit does not declare gives W_SPICE_UNKNOWN_PARAM (still applied);
  4. local .PARAM lines inside the subcircuit, in order. Redefining a default/override parameter locally is an error (E_SPICE_PARAM_REDEF).

Annotated example with nesting (bundled cap_0603_10uF.mod)

The text on the right of each line is an explanation, not part of the file (except the ; and $ inline comments, which are real comments).

* 10 uF 0603 X5R MLCC with nested ESL/ESR branch
.PARAM CNOM=10u                                   global parameter
.SUBCKT CAP_0603_10UF PIN1 PIN2 PARAMS: CDER=0.9  top-level subckt, 2 pins, default CDER
X_ESL PIN1 N1 RL_BRANCH PARAMS: LS=0.5n           call RL_BRANCH with LS = 0.5 nH ...
+ RS=3m                                  ; continuation line: ... and RS = 3 mΩ
C1 N1 N2 {CNOM*CDER/0.9}                 $ expression: 10u*0.9/0.9 = 10 uF
R2 N2 PIN2 2m                                     2 mΩ
RLEAK N1 PIN2 100MEG                              leakage 100 MΩ (MEG, not M!)
.ENDS CAP_0603_10UF

.SUBCKT RL_BRANCH A B PARAMS: LS=1n RS=1m         defaults, overridden by the call above
L1 A M1 {LS/2}                                    0.25 nH
L2 M1 M2 {LS/2}                                   0.25 nH
K12 L1 L2 0.0                                     coupling (k = 0 here)
R1 M2 B {RS}                                      3 mΩ
.ENDS RL_BRANCH

After flattening, the circuit is R = 3 mΩ + 2 mΩ, L = 0.5 nH, C = 10 µF: SRF = 2.25 MHz, |Z| at SRF ≈ 5 mΩ.

Which subcircuit is used?

  • If the decap row has a Subckt name, that subcircuit is used.
  • Otherwise the tool looks for subcircuits that are not called by any other subcircuit in the file. If there is exactly one, it is used; if there are several (a vendor library with many part numbers), the first one with 2 pins is used and W_SPICE_MULTI_TOP is shown – set the Subckt column to choose explicitly.
  • The chosen subcircuit must have exactly two pins: pin 1 connects to PWR, pin 2 to GND. For a capacitor model the orientation does not matter.

Using vendor models

  • Many vendors provide one .mod/.lib file per part or a library with many parts; the latter needs the Subckt column.
  • Models with DC-bias or temperature dependence that use behavioural sources are not supported; ask the vendor for a "simple" or "linear" RLC model at the desired bias, or use a measured .s2p file.
  • Some models already include mounting inductance for a reference layout; then keep the mounting inductance setting at 0.
  • Always verify with Preview model: the curve should fall at −20 dB/decade, dip at the SRF and rise above it.
