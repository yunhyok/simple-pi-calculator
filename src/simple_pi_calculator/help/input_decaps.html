Input: Decap list

The decap list assigns groups of identical decoupling capacitors to the PWR nets. One row = one decap row: N capacitors of the same model, at the same distance from the PAD, spread across the plane width. Rows are imported from Excel (Decaps tab ▸ Import… or File ▸ Import ▸ Decap List…) or added with Add (the PWR name is pre-filled from the filter box).

The Decaps table

Columns: Enabled, PWR Name (drop-down list), Decap File (type a path or press … to browse), Subckt, S2P Mode, Count, Distance mm, Dummy Cap (check box), and the derived columns Via sets (number of cavity ports of the row), C @100 kHz (capacitance of one model at 100 kHz) and SRF MHz (self-resonance frequency of one model). Preview model plots |Z| of the selected model alone – a quick check that the file is read as expected.

The filter box at the top ("All PWRs" or one name) follows the row selected in the PWR Nets tab.

The second line of the tab holds the global Distance distribution (Fixed or Normal (±1σ)), σ (mm), Seed and New seed; see Distance distribution. σ and the seed are disabled in Fixed mode.

Distance to PAD and placement

The real component coordinates are not needed. For each PWR net the tool places:

  • the PAD at x = W/2, y = 0.2 × D_ref, where D_ref is the largest distance of the net;
  • each decap row on the line y = 0.2 × D_ref + distance, i.e. Distance to PAD is measured along y, perpendicular to the row;
  • the via sets of a row evenly across the width, keeping a margin of 10 % of W plus half a port at each side; a row with a single via set sits directly opposite the PAD at x = W/2;
  • if a row does not fit in one line (usable width / number of via sets < port width), it is split into several sub-rows at a pitch of one port width, centred on the row line.

Figure 1 – Placement of the PAD and two decap rows. Capacitors near the plane sides are farther from the PAD than the row distance.

This mimics a row of capacitors along a board edge or a capacitor bank opposite the IC. Capacitors spread across the width are farther from the PAD than the entered distance (√((x − W/2)² + d²)), which is physically correct for such a row. For a cluster of capacitors all close to the IC, use a small width or enter the capacitors as several rows with their actual distances.

Distance distribution

Real capacitors of one row are rarely all at exactly the same distance. The Distance option at the top of the Decaps tab applies to every decap row of every PWR net:

ModeDistance of each via set
Fixed (default)Exactly the row's Distance to PAD D. This is the behaviour of version 0.2.0; results are unchanged.
Normal (±1σ)d = D + σ·z, where z is drawn from a standard normal distribution truncated to [−1, 1]. Every distance therefore lies between D − σ and D + σ; values near D are more likely.

The truncated normal distribution on [−1, 1] has the density φ(z)/(Φ(1) − Φ(−1)) inside the interval and 0 outside (φ, Φ: standard normal density and distribution function) [JKB94]. Its standard deviation is 0.540·σ, so the entered σ is the half-width of the allowed band rather than the spread of the samples. The tool draws u uniformly from [0, 1) and uses z = Φ⁻¹(Φ(−1) + u·(Φ(1) − Φ(−1))) (inverse-transform sampling).

  • σ (mm): absolute standard deviation, 0.01 … 50 mm, default 0.5 mm.
  • Seed: integer 0 … 2147483647, default 12345, stored in the project. The same seed and inputs always give the same distances and the same results (also on another computer). New seed draws a different random seed.
  • Order: one random sequence per computation, used by the enabled rows of the decap table from top to bottom (all PWR nets), and within a row by the via sets in port order. Adding, removing, enabling or disabling a row, or changing a count, therefore changes the samples of the rows below it.
  • Dummy Cap rows: a via set carrying two capacitors gets one sample – the pair shares its vias and moves together.
  • Geometry: each via set keeps its x position (and sub-row pattern) and is moved in y by d − D. The plane height uses the largest sampled distance: D_ref = max d, H = 1.4·D_ref. Ports that would leave the plane are moved to the edge (W_DECAP_CLIPPED).
  • The PWR Nets preview shows the scattered via sets; hover a via set to see its row, index and distance. After a computation the Messages dock lists I_DIST_SAMPLED with σ, the seed and the min/mean/max distance per PWR net, and CSV/Touchstone exports record the same summary in their header.
Note. One seed is one possible layout. To judge the spread of |Z| caused by distance variations, compute several seeds and compare the curves. A σ close to or larger than the distance itself lets via sets reach the PAD row (W_DIST_SIGMA_LARGE).

Dummy Cap

A dummy cap is a capacitor without vias of its own: it is connected by pads/traces to an adjacent capacitor and shares that capacitor's via set. Designers use this to place more capacitance than there is room for vias. With Dummy Cap = Yes, half of the capacitors of the row are assumed to be dummies:

via sets (ports)    P = ceil(N / 2)
capacitors per port = 2, 2, …, 2       and 1 on the last port when N is odd
load of a port      Z_L = Z_cap / (capacitors on the port) + Z_via,dec

The two capacitors on one port are ideal parallel paths; the extra pad/trace between them and their mutual coupling are neglected (use the mounting inductance setting for a rough allowance). The shared via set stays in series, so a dummy pair gives less benefit than two capacitors with their own vias.

Where model files are searched

For a relative path the first existing location wins:

  1. the path itself if it is absolute;
  2. relative to the folder of the imported decap Excel file;
  3. relative to the folder of the project file (.spical.json);
  4. relative to the Model search folder (Vias tab ▸ Advanced).

The file extension selects the reader: .mod .lib .sp .cir .sub .inc → SPICE (format), .s2p → Touchstone (format). Identical models (same file, subcircuit and S2P mode) are computed only once.
