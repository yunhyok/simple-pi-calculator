Limitations

Simple PI Calculator is a first-order planning tool. Knowing what it leaves out helps you judge the numbers. "Optimistic" means the real impedance is likely higher than computed, "pessimistic" means likely lower.

#TopicLimitation and effect
1No VRM / DC pathNo voltage regulator or bulk supply is modelled, so |Z| rises without limit (capacitively) towards low frequency. A real PDN flattens to the regulator output impedance below roughly 10–100 kHz. Bulk capacitors can be entered as ordinary decap rows.
2Plane shapeOnly solid rectangular planes: no cut-outs, split planes, irregular outlines, anti-pad fields or neighbouring cavities. Only the one GND layer you select is used; a PWR plane between two GND planes is modelled with one cavity (pessimistic).
3Synthetic geometryThe plane height is derived as 1.4 × the largest decap distance, the PAD and decap rows are at opposite ends, and decaps are spread evenly across the width. Real outlines, component coordinates and orientations are not used. Plane capacitance and plane resonance frequencies are those of the synthetic plane. The PAD is only 0.2 × D_ref from a plane edge, which increases the PAD–decap spreading inductance by typically 10–15 % compared with a large plane (pessimistic). All components are on the Top side.
4Dummy capsTwo capacitors share one via set as ideal parallel paths; the pad/trace between them and their mutual coupling are neglected (only the optional mounting inductance per capacitor is added) – optimistic.
5Via modelTwo-conductor via-pair loop with one via pitch for all pairs, plus the anti-pad segment through the nearer plane. Mutual inductance between parallel via pairs is neglected (optimistic for more than 1 via per decap pad or more than 1 PAD via pair). The default mounting inductance of 0 nH is optimistic – typical 0402/0603 pad and escape inductance is 0.2–0.6 nH per capacitor. Via barrel capacitance, via stubs below the far plane, vias passing through other planes and the component body are not modelled.
6Port modelA via or via cluster is represented by a square port of equal geometric mean distance, with a fixed checkerboard arrangement of pitch √2 × via pitch for clusters. Error below 1 % for via spacing ≥ 10 × drill and about 5 % at 2 × drill. Ports closer than their widths are unphysical (W_PORT_OVERLAP).
7DielectricDk and Df are constant over frequency (no dispersion model); anisotropy is ignored.
8ConductorsSmooth copper, no surface roughness; skin effect included through the surface impedance of planes of the given thickness.
9Frequency rangeThe cavity model assumes the dielectric is much thinner than the wavelength and neglects radiation and edge fringing. Accuracy degrades above a few GHz (warning above 3 GHz, hard limit 20 GHz). Edge fringing capacitance is neglected (a few %).
10Decap modelsSPICE: only linear R, L, C, K subcircuits; no .INCLUDE/.LIB, behavioural sources, LAPLACE elements, temperature or DC-bias derating. Touchstone: the file includes its fixture parasitics; extrapolation outside the file range is simple.
11IC sideNo die capacitance or package model; the PAD is an ideal observation port at the board/substrate surface.
12NumericsSweep start at 1 kHz or higher. The limit of 1500 modes per axis may slightly under-resolve the spreading inductance for very large planes with very small drills (W_MODES_CAPPED). Computation uses all CPU cores by default (Vias → Advanced → Worker threads). Plane matrices are kept in memory between runs (up to about 500 MB), so changing only decap models, the via model or the mounting inductance recomputes quickly; changing the plane, the decap counts or distances, the via drill/pitch/counts, the stack-up or the sweep recomputes everything. A very large net (more than a few hundred decap ports) needs memory for a frequency × ports × ports matrix (e.g. 400 points × 121 ports ≈ 94 MB).
13PersistenceOnly one running instance auto-saves. Computed results are not stored; they are recomputed on restore.

Using the results sensibly

  • Best use: comparing variants (number and value of decaps, distance, via count and pitch, plane depth) and first estimates of the mid-frequency impedance.
  • Treat plane resonances and the plane-only curve as indicative; verify final designs with a tool that uses the real layout.
  • Set a realistic mounting inductance before comparing with measurements.
